# NDHCE Progress Tracking Upgrade

This update adds browser-based detailed tracking for all nine subject modules.

Captured fields:
- question ID
- module
- concept
- practice or exam
- visual or text
- selected answer
- correct answer
- correct or incorrect
- first-attempt flag
- timestamp
- session ID
- session score and duration

The Overall Dashboard adds:
- total attempts
- overall accuracy
- unique questions seen
- visual-question accuracy
- performance by module
- weak concepts
- recent sessions
- JSON backup export
- CSV export

The existing per-module summary counters remain compatible.
